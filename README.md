# Chat — estructura modular

## Estructura
- `index.html` — interfaz y estructura visual.
- `css/styles.css` — todos los estilos.
- `js/app.js` — lógica del chat, cámara, audio, mensajes y notificaciones.
- `config/firebase-config.js` — configuración de Firebase.
- `assets/` — reservado para imágenes, iconos u otros recursos locales.

## Importante
Se conserva la lógica del archivo original. Para ejecutar el proyecto, sirve esta carpeta desde un servidor HTTPS o localhost cuando uses las notificaciones del navegador.
